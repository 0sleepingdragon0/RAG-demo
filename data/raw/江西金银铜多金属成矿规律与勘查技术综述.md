> **数据声明**：本文为 RAG Demo 用合成文档，是对其余各矿床文档的归纳层，用于支撑跨文档综合类问答。

## 1. 大地构造位置

江西省地处**华南板块**内部，跨扬子陆块东南缘与华夏地块，两者的缝合带即**钦杭结合带（钦杭成矿带）**。钦杭成矿带位于华南板块东南缘，自广西钦州延伸至浙江杭州，**江西段处于该带东段的核心区域**，是省内金银铜多金属矿产最主要的成矿构造单元。省内另有两个重要成矿带：北部的**长江中下游成矿带**（九瑞矿集区属之）与南部的**南岭钨锡成矿带东段**。区域深断裂包括**赣东北深断裂、十杭裂谷带、江山—绍兴断裂带、萍乡—广丰深断裂、郯庐断裂带（安徽段）**，它们控制岩浆带分布与矿化定位。

## 3. 矿床类型的定义与判别要点

**斑岩型矿床**：矿化产于中酸性小岩体（斑岩体）内部及顶部，与浅成—超浅成侵入体相关，矿体体积大而品位低，典型蚀变分带由内到外为**钾化带 → 绢英岩化带 → 青磐岩化带 → 泥化带**，与铜矿化关系最密切的是绢英岩化带和钾化带。

**矽卡岩型矿床**：中酸性侵入体与**碳酸盐岩（石灰岩、白云岩）**在接触带经接触交代变质作用形成，围岩蚀变以石榴子石、透辉石矽卡岩化为特征，矿体多呈透镜状、似层状，品位通常高于斑岩型（Cu 1.2% ~ 2.4%）。按产状进一步分为围绕岩体的**接触带矽卡岩型**（武山南矿带）与沿层间发育的**层状/层控矽卡岩型**（永平、武山北矿带）。

**火山岩型矿床**：矿化赋存于火山喷发岩或潜火山岩中，受火山机构（破火山口、火山塌陷构造）与环状、放射状断裂控制，如银山铅锌银矿与相山铀矿田。

**石英脉型黑钨矿床**：矿脉充填于花岗岩体内近东西向剪切节理中，呈"五层楼""三层楼"垂向分带，属汽化—高温热液充填矿床，是我国石英脉型钨矿中最重要的类型，储量约占全国的 25%，集中分布于赣南、粤北、湘南。

## 4. 赣东北地区金铜多金属成矿规律

以德兴—乐平—婺源一带为中心的赣东北是江西省金银铜矿产的核心区，成矿规律可归纳为五点：

1. **成矿时代集中**：主成矿期为燕山早期 175 ~ 155 Ma，德兴含矿斑岩 172 ~ 165 Ma、银山火山岩 176 ~ 166 Ma，两者属同一期岩浆—成矿事件；
2. **矿床类型组合**：以斑岩型铜（金）矿为主，伴有矽卡岩型与热液脉型，浅部铅锌银、深部铜金分带明显；
3. **构造控制**：成矿受赣东北深断裂及其次级北东向、北西向断裂交汇部位控制，德兴—金山复式背斜轴部出露双桥山群；
4. **地层控制**：**双桥山群浅变质碎屑岩是铜的初始矿源层**，Cu 背景值高达 50 ~ 150 ppm，其变质杂砂岩与硅质岩构成化学障；
5. **成矿母岩**：富铜的中酸性—基性岩浆岩，花岗闪长斑岩以岩筒、岩株产出，矿化沿断裂呈带状分布，构成德兴斑岩铜矿带；
6. **成矿系统观念**：德兴铜矿—银山铅锌银矿—金山金矿—蛤蟆石金矿被认定为属**同一成矿系统**，是"三位一体"找矿预测的基础。

## 5. 主要勘查技术手段与适用场景

| 技术手段 | 主要用途 | 最适用矿床类型 |
|---|---|---|
| 区域地质调查（填图） | 建立地层—构造—岩浆格架，基础工作 | 全部类型 |
| 磁法测量 | 识别含磁铁矿钾化带、磁性岩体、玢岩铁矿 | 斑岩型、玢岩型铁矿 |
| 重力测量 | 推断隐伏岩体密度界面、接触带形态 | 矽卡岩型 |
| 激电法（IP） | 硫化物富集区高极化率异常，圈定隐伏斑岩体最有效 | 斑岩型铜矿、层状矽卡岩型 |
| 土壤/水系沉积物地球化学测量 | 元素异常定位与组合分带 | 全部类型 |
| 汞气（Hg）与氡（Rn）测量 | 断裂通道与深部矿化指示 | 铀矿、脉型矿 |
| 遥感（TM/高光谱）解译 | 线环构造、蚀变带识别 | 火山岩型矿床 |
| 槽探/钻探（岩心编录） | 异常验证、确定蚀变分带与品位 | 全部类型 |
| 同位素年代学（锆石 U-Pb、Re-Os、Ar-Ar） | 厘定成岩成矿时代与成岩成矿时差 | 成矿规律研究 |

按矿床类型的组合建议：**斑岩型重 IP + 磁法 + Cu-Mo-Au-As 土壤组合异常**；**矽卡岩型重重力 + 化探 + 接触带填图**；**火山岩型（银山、相山）重遥感线环构造解译 + 蚀变填图 + 放射性测量**；**石英脉型钨矿重地质填图 + 脉群分带测量 + W-Mo-Bi-Sn 组合异常**。

## 6. 地球化学异常组合与矿化对应关系

- **Cu-Mo-Au-As**：指示斑岩型铜（金）矿化
- **Cu-Mo-Bi-W**：指示斑岩—矽卡岩型矿化
- **Cu-S-W-Pb-Zn（含白钨矿）**：指示层状矽卡岩型铜多金属矿（永平式）
- **Pb-Zn-Ag**：指示中低温脉状与火山岩型矿化
- **Au-As-Sb**：指示浅成低温热液型金矿
- **V-Ti-P**：指示玢岩型铁矿
- **W-Mo-Bi-Sn + Cs、Rb、Th、U 富集，Ba、Sr、Ti 亏损**：指示壳源重熔花岗岩有关的石英脉型钨矿
- **U-Ra-Rn**：指示火山岩型铀矿

## 7. 资源地位与找矿方向

江西是中国钨、铜、铅、铀的重点省份：相山为**中国最大火山岩型铀矿田**，西华山为**大型黑钨矿床（WO₃ 8.13 万 t）**，德兴为**亚洲最大斑岩型铜矿**，永平为**江西第二大铜矿**。当前找矿方向集中于：已知矿山深边部（德兴、武山北矿带、永平西部外围隐伏矿体、梅山与罗河深部）、火山机构深部（银山、相山深部 Pb-Zn-Ag），以及钦杭结合带与南岭带覆盖区的第二找矿空间。
