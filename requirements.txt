# 版本约束链（2026-10-24 定位，别随手放开上限）
# ------------------------------------------------------------
# setup_env.bat 装的是 CUDA 12.1 轮子 -> torch 最高只能到 2.5.1
#   transformers>=5.0 硬性要求 torch>=2.6，否则 is_torch_available()
#   返回 False，transformers/integrations/accelerate.py 里的
#   "import torch.nn as nn" 不执行，第 65 行的注解直接
#   NameError: name 'nn' is not defined -> FlagEmbedding 无法导入
#   => 所以 transformers 必须 <5.0
# transformers 4.x 要求 huggingface-hub<1.0
#   => datasets 必须 <4.0（datasets 4/5 要 hub>=1.x）
#   => ragas 必须 <0.3.3（要 datasets>=4）
# sentence-transformers>=6.0 要求 transformers>=5.0
#   => 必须 <6.0
#
# 想放开这些上限，只有一条路：把 torch 升到 >=2.6
# （setup_env.bat 里的 cu121 换成 cu124/cu126，约 3 GB 下载），
# 那时可以整体回到最新栈：transformers 5 + hub 2 + datasets 5 + ragas 0.4。
